# Homo oeconomicus

Modèle théorique de l'agent économique dans la pensée néoclassique ([[Marginalisme\|Marginalisme]]) : individu isolé (individualisme méthodologique), parfaitement rationnel, qui cherche exclusivement à maximiser son intérêt personnel sous contrainte (utilité pour le consommateur, profit pour le producteur), par opposition à l'agent doté de sentiments moraux chez [[Adam Smith\|Adam Smith]].
