# Nouveau Code pénal de 1992

Issu de quatre lois du 22 juillet 1992 et entré en vigueur le 1er mars 1994 en remplacement du Code pénal napoléonien de 1810, le nouveau Code pénal a notamment consacré pour la première fois la responsabilité pénale de la [[Personne morale\|Personne morale]] (généralisée ensuite par la [[Loi du 9 mars 2004\|Loi du 9 mars 2004]]).
