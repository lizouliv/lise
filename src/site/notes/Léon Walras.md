# Léon Walras

**Léon Walras (1834–1910)** — Économiste français, fondateur de l'école de Lausanne et cofondateur du [[Marginalisme\|Marginalisme]].

- *Éléments d'économie politique pure* (1874) : mathématise les échanges et formalise le modèle d'[[Équilibre général\|Équilibre général]] simultané de tous les marchés par les prix.
